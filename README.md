# ☀️ Weather-App

It is a modern, sleek weather forecasting application for Android that provides real-time weather updates, forecasts, and personalized weather insights.

## 📱 About

Weather-App is a feature-rich weather forecasting application built with modern Android development practices. It delivers accurate weather information with a beautiful, intuitive user interface and supports user personalization through Firebase integration.

## ✨ Features

- **Real-time Weather Data:** Current temperature, humidity, wind speed, and atmospheric pressure
- **14-Day Forecast:** Hourly and daily weather predictions
- **Location-based Weather:** Automatic weather detection for current location
- **City Search:** Search and save favorite locations worldwide
- **Weather Alerts:** Severe weather notifications and updates
- **User Profiles:** Save preferences and favorite locations with Firebase
- **Dark/Light Theme:** Automatic theme switching based on system settings

##  Tech Stack

| Layer | Technology |
|-------|------------|
| **Language** | Kotlin |
| **UI Toolkit** | Jetpack Compose |
| **Architecture** | MVVM (Model-View-ViewModel) |
| **Dependency Injection** | Hilt (Dagger-Hilt) |
| **Backend Services** | Firebase (Authentication, Firestore) |
| **Networking** | Retrofit + OkHttp |
| **Asynchronous** | Kotlin Coroutines + Flow |
| **Image Loading** | Coil |
| **Location** | Google Play Services Location |
| **Permissions** | Accompanist Permissions |
